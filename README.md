# VisitK
Бот-визитка, которая работает на тебя, пока ты спишь.
Рассказывает о тебе, показывает портфолио и даёт контакты — без простыней текста, всё на инлайн-кнопках.

Что внутри
 
Токен живёт в `.env` на твоём ПК и никогда не попадает в git.
Быстрый старт
```bash
# 1. Получи токен: @BotFather в Telegram -> /newbot
# 2. Создай .env из шаблона
cp .env.example .env        # Windows: copy .env.example .env
# 3. Впиши токен в .env
# 4. Запуск
node bot.js
```
Всё. Бот в сети, можно писать ему `/start`.
Настройка под себя
Всё содержимое — в `config.json`:
Поле	За что отвечает
`start\_text`	Приветствие при `/start`
`about`	Текст раздела «Обо мне»
`portfolio`	Массив проектов — каждый станет инлайн-кнопкой
`contacts\_text`	Текст раздела «Связаться» (сюда же почту)
`contacts`	Кнопки-ссылки: Telegram, GitHub, сайт и т.п.
Добавить проект в портфолио
Дописываешь объект в массив `portfolio` — кнопка появляется сама:
```json
{
  "title": "Мой крутой проект",
  "description": "Что это и зачем.",
  "url": "https://github.com/username/project"
}
```
Перезапуск не нужен: бот читает конфиг при каждом запросе.
Контакты
В `contacts` — только ссылки (`https://...`, `https://t.me/...`): Telegram не разрешает кнопки с `mailto:`.
Почту, Discord-тег и прочее без ссылки впиши текстом в `contacts\_text`.
А где токен?
В файле `.env`, который прописан в `.gitignore`. В репозитории лежит только `.env.example` с заглушкой —
клонировал, скопировал, вписал свой токен, запустил.
Если токен всё же утёк: `@BotFather -> /revoke` — старый умирает, выдаётся новый. Меняешь его в `.env`, и всё.
Структура
```
tg-portfolio-bot/
├── bot.js           # вся магия, один файл
├── config.json      # тексты, проекты, контакты
├── .env             # токен (только на твоём ПК, не в git)
├── .env.example     # шаблон для .env
├── .gitignore
└── README.md
```
Требования
Node.js 18 или новее — нужен встроенный `fetch`. Больше ничего.
